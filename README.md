# OfficeSelfSigningPortal

Self-Service-Portal zur automatisierten Analyse und digitalen Signierung von MS-Office-Makros (.xlsm, .docm, .pptm) — auf Basis von .NET Aspire, RabbitMQ/MassTransit und PostgreSQL.

**Ausführliche Dokumentation (Sicherheit, Architektur, Betrieb): [`docs/anwendungsdokumentation.md`](docs/anwendungsdokumentation.md)**

## Schnellstart

Noch nicht verfügbar — die Lösungsstruktur (Aspire AppHost, WebUI, WorkerService, SigningService) entsteht im Secure-SDLC-Feature-Workflow. Build- und Run-Anleitung folgen im Betriebshandbuch (Anwendungsdoku §14).
